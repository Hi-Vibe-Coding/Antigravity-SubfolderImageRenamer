# Antigravity-SubfolderImageRenamer (v0.0.1)

基于 **Electron + Vue 3 + TypeScript + Vite + Element Plus** 构建的桌面端自动化图片批量重命名工具。

---

## 功能特性

1. **操作模式切换**：
   - 顶部菜单支持切换【模式1：子文件夹模式】与【模式2：父文件夹模式】。
2. **模式1：子文件夹模式**：
   - **添加子文件夹**：支持点击“添加子文件夹”按钮选择目录，或直接向面板拖拽单个/多个子文件夹。
   - **小图标展示**：每次添加子文件夹，面板中心以网格卡片展示文件夹小图标与名称，支持多次添加与手动移除。
   - **状态锁定**：点击右下方“开始扫描”后，界面自动锁定添加入口，防止误操作。
   - **第一层扫描**：只扫描每个目标子文件夹（如 `E1-013`）第一层的图片文件（`.png`、`.jpg`、`.jpeg`、`.webp`）。
   - **纯数字检测与自动重命名预览**：
     - 主文件名若为纯数字（例如 `1.png`、`12.png`），自动构造目标新名称（如 `E1-013__1.png`）。
     - 列表中每一行展示直观映射描述（`1.png` -> `E1-013__1.png`），并默认勾选。
     - 非纯数字文件明确标注并保持原名。
   - **开始改名与进度反馈**：
     - 点击最下方“开始改名操作”，弹出安全确认后开始执行。
     - 底部进度条实时展示当前完成进度与百分比。
     - 改名成功后列表状态即时刷新，并支持一键在系统资源管理器中定位文件。

---

## 本地运行与开发

```bash
# 1. 安装依赖（已完成）
npm install

# 2. 启动开发模式（秒级启动开发窗口）
npm run dev

# 3. 编译打包生成 Windows 可执行程序
npm run dist
```
